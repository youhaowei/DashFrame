# @dashframe/engine-browser

Browser-side Arrow helpers for local file ingest. Query execution is the
server native DuckDB engine, not DuckDB-WASM.

## What this package owns

| Export                         | Use                                                      |
| ------------------------------ | -------------------------------------------------------- |
| `createArrowIPCBufferFromRows` | Encode parsed CSV/JSON rows as Arrow IPC for host ingest |
| `shortenAutoGeneratedName`     | Display names for auto-generated tables                  |

It also re-exports `@dashframe/engine` so parsers can import field helpers
from one place.

There is no in-browser query engine, IndexedDB frame store, or DuckDB-WASM
binding.
